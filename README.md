# test_routine

Demostración de una rutina en la nube de Claude Code: cada pull request hacia
`main` dispara una revisión automática que aplica la lista de `CLAUDE.md`,
corre las pruebas y deja un comentario en el PR.

- `sla.py`: suma horas hábiles (lunes a viernes, 08:00 a 17:00) a una fecha con zona horaria.
- `test_sla.py`: pruebas con `unittest`.

Todo el contenido es inventado.
